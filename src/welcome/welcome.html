Using an AI coding agent?

Two settings let an agent like Claude Code or Cursor read your captures, or take them itself:

  • Output folder. Pick a folder and every capture also writes latest.md and latest.jpg there, so you can tell your agent "check my capture" instead of pasting.
  • Which pages can trigger a capture. Off by default. Choose "Allowed sites" and an agent driving localhost can capture without a keystroke.

Privacy

Capture Kit has no server and no analytics. Screenshots and reports are written to your computer and your clipboard, and nowhere else. Common secret formats that show up in console messages or request URLs - API keys, access tokens, auth headers - are blanked out of the report text before it's saved. The screenshot itself shows what was on screen, so check it before sharing.
