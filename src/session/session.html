capture-kit

Capture session

Capture several tabs into one folder with an index that lists, per page, the console errors and network failures — the file you hand an AI assistant.

Reloading loses unsaved page state — forms, editors, anything not yet submitted. Left off, tabs opened before the extension loaded will report console data as unavailable rather than pretending they are clean.

During the run the browser switches to each tab in turn. That is expected: Chrome does not render a tab that is not in front, so a backgrounded tab would capture blank.
